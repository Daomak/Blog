三菱系统传输与修复

发表于2024-03-18|更新于2026-11-02|工作笔记
|总字数:1.4k|阅读时长:4分钟|浏览量:

一、前期准备

  1. 软件安装包：NC Explorer（M80V需要最新版的软件），安装完成必须重启电脑。
  2. 网线：
    • 电脑直连单台机床：新网卡支持自动线序翻转，直通线可用；老网卡建议交叉线
    • 交换机多机床组网：全部使用标准直通网线
  3. 网口位置：M80网口一般在操作面板背面，部分机床没有引出外接网口，需要拆开面板接线
  4. 权限提醒：修改机床以太网参数需要维护密码，常见维护密码：MPARA

二、机床端以太网参数设置（重点）

进入路径：【维护】→【参数】→ 翻页找到【以太网参数】，直接搜索参数号：

参数号 作用 示例
#1925 以太网功能开关 1=开启，0=关闭（很多人连不上就是漏设这个）
#1926 机床IP地址 192.168.1.100
#1927 子网掩码 255.255.255.0
#1928 网关 单机直连留空；交换机局域网填写路由器网关

设置完成后，重启机床，网络参数才生效。
规则：电脑IP与机床IP前三段网段一致，最后一段不能重复，避免IP冲突。

三、电脑网卡静态IP设置

  1. Win+R 输入 ncpa.cpl，打开网络适配器列表
  2. 右键【以太网】→ 属性 → Internet协议版本4（TCP/IPv4）
  3. 使用下面静态IP（和上面机床示例配套）
    • IP地址：192.168.1.200
    • 子网掩码：255.255.255.0
    • 网关、DNS：单机直连留空；组网环境按路由填写
  4. 保存。

连通性测试（CMD执行）

  • 能正常 ping 通：网络底层没问题，问题在软件、账号、防火墙
  • 请求超时：回头查 #1925、网线、机床网口灯、IP 网段

端口说明：NC Explorer 通讯端口 683，防火墙需要放行该端口。

四、NC Explorer 添加机床、账号密码

添加完成后，NC Explorer资源管理器内会多出机床文件夹，内部一般包含：

  • MEMORY：机床程序内存（O 程序）
  • CARD：系统存储卡
  • USB：机床 USB 存储

多网卡电脑特殊用法

电脑同时有无线、多张网卡，指定网卡连接机床，快捷方式启动参数：

/NIC 后面填写本机用来连机床的网卡 IP，避免软件选错网卡搜不到机床MITSUBISHI…。

跨网段机床添加

托盘图标右键 → Subnet，添加其他网段子网信息，重启软件生效，用于跨路由访问机床MITSUBISHI…。

五、程序上传下载规范（必看，防止报警）

NC 程序标准格式

程序首尾必须带 %，换行格式为 CR+LF（Windows 换行）

  • 禁止 LF 单行换行（Linux 格式），上传后机床报格式错误
  • 程序名：O + 最多 4 位数字，禁止中文、空格、特殊符号、长文件名
  • 文件后缀：推荐 .nc、.txt

操作流程

  1. 下载（机床→电脑）：直接从机床 MEMORY 文件夹复制程序到电脑备份
  2. 上传（电脑→机床）：写好的 NC 文件拖拽进 MEMORY 文件夹

注意：机床处于【自动运行】状态时，部分系统禁止写入程序、参数，切换到编辑模式操作。

参数、刀补备份

参数文件（PRM）、刀具补偿、宏变量都可以直接复制出来备份，还原的时候拖入机床对应目录，还原参数后必须重启 CNC。

六、常见故障排查清单

表格

故障现象 排查步骤
ping 正常，但 NC Explorer 无法访问机床文件夹 1. 核对账号密码；2. Windows 防火墙放行 683 端口；3. 检查 hosts 文件缺失 / 损坏；4. Win11 注册表异常，使用 NERT 修复工具
搜不到机床、添加设备提示超时 1. #1925 是否设为 1；2. 网口指示灯；3. IP 网段；4. 杀毒软件拦截
拖拽上传报错、传输中断 1. 程序缺少%、换行符错误；2. 文件名非法；3. 机床内存已满；4. 网线屏蔽不良、变频器干扰
打开文件夹提示 “无法访问此文件夹” 经典问题，优先检查 C:\Windows\System32\drivers\etc\hosts 文件，文件丢失会解析失败；其次用 NERT 修复 NC Explorer 注册表项
Win11 安装后打不开、闪退、托盘图标消失 NC Explorer 原生不支持 Win11，注册表项容易损坏，使用本站 NERT 工具修复
一台电脑只能识别部分机床 检查子网配置、是否开启了多网卡选错网卡，使用/NIC参数指定网卡

七、配套工具与避坑要点

  1. NERT（NC Explorer Repair Tool）：本站提供下载，专门修复 NC Explorer 注册表损坏、启动报错、Win11 兼容问题
  2. VS Code：编辑 NC 程序，开启显示换行符，快速检查 CRLF 格式

重要安全提醒

  1. 机床局域网不要接入互联网，避免外部访问 CNC
  2. 传输、修改参数前，务必做好完整备份
  3. 屏蔽网线和动力线、变频器动力线分开走线，屏蔽层单端接地，减少传输乱码丢包
  4. 不要在机床加工运行中修改参数、上传覆盖正在使用的程序

免责声明：本文为现场调试笔记，操作机床参数、网络设置务必熟悉设备安全规范，误操作造成加工事故、参数丢失自行承担风险。
