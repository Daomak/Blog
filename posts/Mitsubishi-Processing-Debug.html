三菱系统加工调试

三菱M70/M80/M800 加工调试参数完整手册

适用：立式加工中心、龙门、雕铣机、模具/石墨机
资料来源：三菱官方《M800/M80 Alarm/Parameter Manual》《SERVO ADJUSTMENT MANUAL》、M70/M80高精度调整资料、SHG控制技术资料
编号差异：M70 主轴参数在 #30xx 段，M80/M800 主轴参数在 #13xxx 段；其余加工/伺服参数两系兼容
安全前提：修改前备份 NC/伺服/补偿参数；单轴、单变量微调；伺服增益改完必须空载试切

一、伺服环基础参数（振动、圆度、跟随误差核心，单轴独立）

官方高精度调整推荐：PGN 尽量设 47（最低 38）、前馈 fwd_g 尽量设 45（最低 40），在不振范围内越高，相同加工时间尺寸精度越好

参数号 代号 名称 标准值/参考 说明
#2203 PGN 位置环增益 33 / 47 尺寸精度优先设高（47），振动则降到33
#2204 PGN2 位置环增益2 按比例 SHG 时与 PGN1、SHGC 按 1:8/3:6 设定
#2205 VGN 速度环增益 按机床 速度环响应，共振啸叫立即降
#2206 VIT 速度环积分时间 20~150ms 消除稳态误差；振动时加大
#2207 DIT 微分时间常数 0~30ms 抑制超调，慎用
#2208 VIA 位置环超前补偿 1364（SHG时1900） SHG 高增益化的关键前置参数
#2010 fwd_g 前馈滤波器增益 40 / 45 前馈越高跟随误差越小、圆弧越圆；过冲则降
#2237 SV037 JL 负载惯量比 150~600% (Jm+Jl)/Jm×100%，干扰观测器前置条件，M80可自动推定
#2215 SV015 FFC 加减速前馈增益 0（SHG时100） 加减速段前馈，改善加减速轮廓偏移

二、干扰观测器 / 扰动补偿

官方《SERVO ADJUSTMENT MANUAL》确认：干扰观测器对 45° 附近圆度、位置偏差波形振动、lost motion 补偿碰撞声均有改善；先设好 #2237 惯量比再调本组

参数号 代号 名称 标准/范围 说明
#2243 SV043 OBS1 观测器滤波频率 300Hz（200~300） 出现振动每次降100；降低后补偿效果变弱
#2244 SV044 OBS2 观测器增益 100~300% 标准100起步，振动则降低
#2216 SV016 LMC1 Lost motion补偿（+方向） 0~100 换向补偿，与SV041配合分方向
#2241 SV041 LMC2 Lost motion补偿（方向依赖） 0~100 设0时用SV016双向；调OBS后需重调lost motion

官方提示：改变 SV043/SV044 后，最优 lost motion 量（SV016/SV041）也随之改变，必须重新调整；观测器对部分机械特性易引发共振，慎用于刚性差的机床。

三、SHG 平滑高增益控制（M80/M800 功能）

SHG 通过更稳定补偿伺服位置环延迟实现高增益化（同样 PGN1 下实际位置环增益约 2 倍），整定时间更短、加减速响应更平滑

参数号 名称 设定 说明
#2257 SV057 SHGC 按比例 与 PGN1(#2203)、PGN2(#2204) 按 1 : 8/3 : 6 设定
#2208 VIA 1900 SHG 时位置环超前补偿标准值
#2215 FFC 100 SHG 时加减速前馈增益标准值
#13035 主轴插补轴 bit C 1 主轴 SHG 开启（M80）
#13036 主轴插补轴 bit 4 1 主轴 SHG 开启（M80）
#2249 SV049 PGN1sp 1 主轴同步控制位置环增益1
#2250 SV050 PGN2sp 8/3 主轴同步控制位置环增益2
#2258 SV058 SHGCsp 6 主轴 SHG 增益

注意：SHG 时速度环必须具有相应响应性，否则加减速照样振动过冲；因机械共振被迫降 VGN 时，需同步减小位置环增益。

四、加减速与滤波器（切削冲击、振纹、轮廓跟随）

参数号 名称 标准/参考 说明
#1206 G1bF 切削最高速度 按需 切削F硬上限，防程序F失控
#1207 G1btL 插补前加减速时间 100ms（50~200） M80变更加速度对轨迹误差影响小，可在不振范围内拉高加速度
#1568 SfiltG1 G01软加减速滤波 50ms（20~50） 抑制振动；对微小圆弧振动无效（用加速度+容差调）
#1569 SfiltG0 G00软滤波 按需 缩短G0时间用
#1570 Sfilt2 第二软滤波 0~20ms 有精度要求设0；减小后振动参考”机械振动”处理

五、SSS / 轨迹精度控制（曲面、电极、微小线段核心）

#8022/#8023 已核实：转角精度系数标准 -100（范围 -1000~99），曲线精度系数标准 30

参数号 名称 标准/范围 说明
#8090 SSS平滑控制 0 / 1 主开关；精加工曲面=1，重切削钢件=0
#8022 角精度系数 CORNER COMP -100（-1000~99） 负值越大越保尖角精度、减速；正值保速度
#8023 曲线精度系数 CURVE COMP 30（0~-300） 圆弧/样条平滑；尺寸精度优先用负值
#8020 转角减速角 DCC ANGLE 0~89° 超过该角度视为拐角并减速；调大节拍快、过切风险高
#8026 取消角 CANCEL ANG 0~180° 精度控制内角度判定行为
#8021 COMP_CHANGE 0 / 1 0：用通用精度系数(#8019 R COMP)；1：用#8022/#8023
#8037 转角判断长度 CorJudgeL 0~99999.999mm 判定小段是否为拐角的长度范围
#8029 Fairing 长度 FairingL 0~100mm 光顺处理作用的块长范围
#8093 阶差宽度 StepLeng -1.0~0.1mm 加工条件选择时阶差/微小几何变化判定宽度
#2659 加工条件组容差 tolerance 0~100mm 加工条件参数组容差值

六、M80 加工条件应用包（模具包隐藏功能，三组一键切换）

M80 参数手册提供三组独立加工条件应用包，参数完全同构、编号平移；程序内配合高速高精度 G 代码调用
粗加工：Application 1 = #42001#42021；半精：Application 2 = #42301#42321；精加工：Application 3 = #42601~#42621

功能 应用1(粗) 应用2(半精) 应用3(精) 范围 说明
G01时间常数 #42001 #42301 #42601 0~5000ms 增大更柔和、周期变长
SfiltG1软滤波 #42002 #42302 #42602 0~200ms 增大表面更干净，过大尖角变圆
Sfilt2第二滤波 #42003 #42303 #42603 0~50ms 曲面短段波纹看这个
通用精度系数 #42004 #42304 #42604 0~99% 对应#8019 R COMP
转角精度 cor_comp #42005 #42305 #42605 -1000~99% 对应#8022
曲线精度 cur_comp #42006 #42306 #42606 -1000~99% 对应#8023
前馈增益 fwd_g #42007 #42307 #42607 0~200% 对应#2010
转角减速角 #42008 #42308 #42608 0~89° 对应#8020
取消角 #42009 #42309 #42609 0~180° 对应#8026
弦误差1(含拐点) #42010 #42310 #42610 0~100mm 小线段轮廓容差，常用0.010
弦误差2(无拐点) #42011 #42311 #42611 0~100mm 同上
Fairing选择 #42013 #42313 #42613 按需 光顺处理
转角判断长度 #42015 #42315 #42615 0~100mm 对应#8037
SSS/Easy SSS #42016 #42316 #42616 0 / 1 每组独立开关
最大加工速度 #42020 #42320 #42620 1~1000000 对应#1206

高速高精度控制模式（程序内调用，模具精加工最常用 G05 P10000）：

  • 型式I：G05.1 Q1 / Q0
  • 型式II：G05 P10000 / P0（模具精加工主力）
  • 型式III：G05 P20000 / P0
    前置许可：#8040 High-SpeedAcc = 1（最多2个part system可开，3个以上触发Y51 0032报警）；调用前先用低风险测试程序确认选项已安装（未安装会报警”No specification”）

七、主轴与刚性攻丝参数

M80/M800 主轴参数为 #13001 段（SP编号）；M70 主轴规格参数在 #3002~#3005 段；以下以 M80 为主

参数号 代号 名称 参考 说明
#13001 SP001 PGV 主轴位置环增益（非插补） 按机床 提高指令追随性、缩短定位整定；过高加减速冲击大
#3002~#3005 - 主轴档位限速（M70） 按铭牌 M70主轴最高/最低转速限制
#2249/#2250/#2258 - 主轴同步位置环增益组 1 : 8/3 : 6 刚性攻丝/主轴插补同步核心，配合#13035/#13036
#8012 - G73啄钻每次退刀量 0.1~2mm 断屑钻
#8013 - G83深孔钻退刀量 2~10mm 深孔排屑，钢件加大

刚性攻丝乱牙排查顺序：主轴同步增益组(#2249/#2250/#2258)比例是否正确 → SHG开启位(#13035/#13036) → 攻丝加减速 → 主轴编码器。不要盲目降转速掩盖问题。

八、反向间隙与误差补偿（换向台阶、定位精度）

参数号 名称 说明
#2011 G00快速反向间隙补偿 定位换向生效
#2012 G01切削反向间隙补偿 轮廓/圆弧换向生效；全闭环光栅机型建议设0
#4001~#4128 螺距误差补偿数据 激光干涉仪采集录入，大修/换丝杠后重测
#4201~#4328 光栅尺误差补偿（全闭环） 光栅线性误差修正
#4400 温度补偿开关 大型龙门温升热伸长补偿
#4401 温度补偿系数 每℃补偿微米值，X/Y/Z独立

九、跟随误差监视（超差停机保护）

参数号 名称 说明
#1330 跟随误差超差监视有效 0/1开启
#1331 跟随误差报警极限值 超过直接伺服报警停止

十、分工艺快速设定参考

  1. 通用高精度起步值：#2203=47、#2010=45、#1207时间常数100、#1568=50、#1570=0~20、#8022=-100、#8023=30
  2. 粗加工（钢料重切削）：#8090=0，PGN/fwd_g偏低档(33/40)，时间常数偏大(100150)，Sfilt2=2030，优先保刚性
  3. 精加工电极/曲面（M80）：#8090=1，G05 P10000，fwd_g=45，#8022=-100-200、#8023=030，Sfilt2=0，弦误差≈0.010
  4. 进一步提速：时间常数降到50、SfiltG1降到20、角精度系数往-300方向
  5. 机械振动时：先降PGN→33方向、用#1568 SfiltG1抑制（注意对微小圆弧无效）、必要时启用#2243/#2244干扰观测器或SHG
  6. 刚性攻丝：主轴同步增益组按1:8/3:6锁定，SHG开启位置1，攻丝加减速专项微调

十一、安全红线

  1. 修改前必须备份参数并记录三组应用包现值；大量改参数会导致运行不稳，未用位保持0
  2. 伺服增益遵循单变量原则，改完空载试切再批量加工
  3. 干扰观测器、SHG 属伺服驱动层高级选项，部分机型需 NC Configurator2 开启选项才生效；M70 无 SHG/OMR/加工条件应用包，参数勿跨系统拷贝
  4. 主轴、伺服、安全类参数超出授权范围禁止修改；参数调整不能替代机械维修（丝杠轴承坏、镶条松靠参数治不了）
