Windows 命令

发表于2026-05-02|更新于2026-11-03|笔记
|总字数:1.6k|阅读时长:6分钟|浏览量:

CMD命令

命令 说明 示例
cls 清空当前窗口屏幕 cls
help 查看内置命令帮助 help dir 查看dir命令详情
ver 查看当前Windows系统版本 ver
whoami 查看当前登录用户名 whoami
date 查看/修改系统日期 date /t 只显示日期
time 查看/修改系统时间 time /t 只显示时间
exit 关闭CMD窗口 exit

文件与目录操作

命令 说明 示例
dir 列出当前文件夹文件 dir /s 递归列出所有子目录文件
cd 切换目录 cd D:\tools、cd .. 返回上一级
md / mkdir 创建文件夹 md test
rd / rmdir 删除空文件夹 rd /s /q test 强制删除带内容文件夹
copy 复制文件 copy a.txt D:\backup
move 移动/重命名文件 move a.txt b.txt
del 删除文件 del /f /s /q *.log 批量删除日志
ren 重命名 ren old.txt new.txt
tree 树形展示目录结构 tree /f 同时显示文件
findstr 文件内搜索关键词 findstr "error" log.txt
where 查找程序路径 where python

网络调试命令（高频）

命令 说明 示例
ipconfig 查看网卡IP信息 ipconfig /all 完整网卡信息
ipconfig /release 释放DHCP获取的IP 管理员执行
ipconfig /renew 重新获取IP地址 管理员执行
ipconfig /flushdns 刷新DNS缓存，解决网站打不开 管理员执行
ping 测试连通性、延迟 ping baidu.com -t 持续ping
tracert 路由追踪，排查丢包位置 tracert baidu.com
nslookup DNS解析查询 nslookup baidu.com
netstat 查看端口连接 netstat -ano 查看所有端口与PID
arp -a 查看ARP缓存表 排查局域网IP冲突
netsh winsock reset 重置网络套接字，修复网络异常 管理员执行，执行后重启电脑

进程与服务管理

命令 说明 示例
tasklist 列出全部运行进程 `tasklist
taskkill 结束进程 taskkill /f /im chrome.exe 强制结束Chrome
taskkill /f /pid 1234 根据PID强制结束进程 1234替换为对应PID号
sc query 查询系统服务状态 sc query wuauserv 查询更新服务
sc start 启动服务 sc start wuauserv
sc stop 停止服务 sc stop wuauserv

磁盘与文件系统（管理员）

命令 说明 示例
chkdsk 磁盘检查修复 chkdsk C: /f /r 修复C盘错误、扫描坏道
format 格式化分区 format D: /FS:NTFS /Q 快速格式化为NTFS
defrag 磁盘碎片整理（机械盘） defrag D: /O
diskpart 磁盘分区工具（交互式） 输入diskpart后继续操作

系统修复、检测命令（管理员）

PowerShell命令

命令 说明 示例
cls / Clear-Host 清空屏幕 Clear-Host
Get-Help 查看命令帮助文档 Get-Help Get-ChildItem -Full
Get-Command 查找可用命令 Get-Command *net* 搜索带net关键词的命令
Get-Location / pwd 查看当前所在路径 pwd
Set-Location / cd 切换目录 cd D:\Tools
exit 关闭窗口 exit

文件与目录操作（核心）

命令 说明 示例
Get-ChildItem / dir / ls 列出目录内文件 Get-ChildItem -Recurse 递归列出所有子文件
New-Item 创建文件/文件夹 New-Item -ItemType Directory test 创建文件夹
New-Item test.txt 创建空白文件
Remove-Item 删除文件/文件夹 Remove-Item test -Recurse -Force 强制删除整个目录
Copy-Item 复制 Copy-Item test.txt D:\Backup
Move-Item 移动/重命名 Move-Item old.txt new.txt
Rename-Item 重命名 Rename-Item test.txt demo.txt
Get-Content 读取文本内容 Get-Content log.txt
Set-Content 写入文本 Set-Content info.txt "测试内容"
Select-String 文件内搜索关键词（类似findstr） Select-String -Path log.txt -Pattern "error"

网络调试命令

命令 说明 示例
Get-NetIPAddress 查看网卡IP地址信息 Get-NetIPAddress -AddressFamily IPv4 只看IPv4
Test-Connection 替代ping Test-Connection baidu.com -Count 4
Resolve-DnsName DNS解析查询（替代nslookup） Resolve-DnsName baidu.com
Get-NetTCPConnection 查看TCP端口连接（替代netstat） `Get-NetTCPConnection
Test-NetConnection 测试端口连通性（非常好用） Test-NetConnection 192.168.1.1 -Port 80
Get-NetRoute 查看路由表 Get-NetRoute

进程、服务管理

命令 说明 示例
Get-Process 获取运行进程 Get-Process chrome
Stop-Process 结束进程 Stop-Process -Name chrome -Force
Get-Service 查看系统服务 `Get-Service
Start-Service 启动服务【管理员】 Start-Service wuauserv
Stop-Service 停止服务【管理员】 Stop-Service wuauserv
Restart-Service 重启服务【管理员】 Restart-Service wuauserv

系统信息、硬件查询

命令 说明 示例
Get-ComputerInfo 获取系统完整信息（Win10 1709+） Get-ComputerInfo
Get-CimInstance Win32_Processor 查看CPU信息 Get-CimInstance Win32_Processor
Get-CimInstance Win32_PhysicalMemory 查看内存信息 Get-CimInstance Win32_PhysicalMemory
Get-CimInstance Win32_LogicalDisk 查看磁盘分区 Get-CimInstance Win32_LogicalDisk
Get-WindowsUpdateLog 导出Windows更新日志 Get-WindowsUpdateLog

Stop-Computer 立刻关机
Start-Sleep -Seconds 60 延时60秒，常用于脚本

管道符 | 用法（PowerShell 精髓）

PowerShell 管道传递对象，不是纯文本，可以直接筛选：

常用过滤关键字：

  • Where-Object {}：条件筛选
  • Select-Object：只挑选指定字段输出
  • Sort-Object：排序

快速打开工具（PowerShell / Win+R 通用）

和 CMD 通用：

  • sysdm.cpl 系统属性
  • services.msc 服务面板
  • devmgmt.msc 设备管理器
  • msconfig 系统配置

注意事项

  1. PowerShell 默认执行策略限制脚本运行，想要运行 ps1 脚本【管理员】执行：

输入 Y 确认；日常只是敲单行命令不需要修改。 2. 区分大小写：PowerShell 命令不区分大小写，但是路径、文件名区分（看文件系统）。 3. 破坏性命令（Remove-Item、格式化等）操作前仔细核对路径，避免误删资料。 4. 适合场景：批量处理文件、自动化脚本、精细化系统信息查询；简单网络排查，CMD 也足够轻便。
