Windows 安装与优化

发表于2026-02-02|更新于2026-11-03|笔记
|总字数:1.6k|阅读时长:4分钟|浏览量:

一、系统安装准备

1. 镜像与启动盘

  1. 前往微软官方网站下载原版 Windows ISO 镜像。
  2. 使用 Rufus 制作U盘启动盘，分区方案选择 GPT+NTFS，适配新主板UEFI启动。

注意：不要使用网络上流传的精简版、Ghost系统，容易捆绑软件、植入后门，缺失必要系统组件。

2. BIOS启动设置

开机按 Del / F2 / F10 进入主板BIOS界面，设置U盘为第一启动项。
推荐开启选项：UEFI启动、安全启动（Secure Boot）；固态硬盘确认开启NVMe协议。

3. 硬盘分区建议

  • 固态硬盘：C盘推荐分配100GB~150GB，剩余空间划分为D盘存放软件、资料。文件系统格式 NTFS。
  • 机械硬盘用作仓库盘，存放素材、备份文件。

4. OOBE部署阶段，跳过强制联网（Win11）

到联网页面时，跳过网络，避免强制登录微软账号：

  1. 在联网界面按下 Shift + F10，调出命令提示符窗口

  2. 输入命令：

  3. 电脑自动重启，再次进入部署界面，就会出现「我没有互联网连接」选项，可以创建本地账户。

提示：安装阶段先不要联网，防止系统后台自动预装一堆应用。

二、系统装好后第一步：安装驱动

驱动安装顺序：芯片组驱动 → 显卡驱动 → 声卡、网卡、外设驱动。

  1. 笔记本电脑：去品牌官网对应机型页面下载官方驱动。
  2. 台式机：主板官网下载芯片组驱动，显卡去NVIDIA或者AMD官网下载。

不推荐驱动精灵、驱动人生，捆绑软件多。可选微软电脑管家，自带驱动检测，无捆绑。

三、隐私与广告关闭

打开「设置 → 隐私和安全性」

  1. 常规：4个广告相关选项全部关闭，关闭广告ID
  2. 语音：关闭在线语音识别
  3. 墨迹书写和键入个性化：关闭
  4. 诊断和反馈：关闭可选诊断数据，反馈频率设置为从不
  5. 活动历史记录：关闭，清除历史记录

关闭系统内置广告

  1. 设置 → 个性化 → 设备使用情况：全部关闭
  2. 设置 → 个性化 → 开始：关闭推荐应用、网站建议
  3. 文件资源管理器：右上角三个点 → 选项 → 查看，取消勾选「显示同步提供程序通知」
  4. 锁屏界面：个性化 → 锁屏界面，关闭有趣事实、提示和广告
  5. 设置 → 系统 → 通知：关闭通知提示、功能建议

四、性能优化设置

1. 视觉效果

Win+R 输入 sysdm.cpl → 高级 → 性能【设置】
自定义勾选：仅保留「在文件夹中显示缩略图，而不是图标」，其余动画效果全部取消。
低配电脑、游戏主机可以直接选择「调整为最佳性能」。

2. 电源计划

设置 → 系统 → 电源和电池

  • 台式机：电源模式改为【最佳性能】
  • 笔记本：插电时使用最佳性能，电池模式选择平衡

3. 虚拟内存（分页文件）

同样在 sysdm.cpl → 高级 → 虚拟内存【更改】
不建议直接关闭虚拟内存，容易造成软件、虚拟机崩溃。
推荐方案：取消自动管理，C盘选择系统管理大小；或者转移到D盘固态硬盘。

内存32G以上可以酌情关闭，16G及以下建议保留。

4. 开机启动项

Ctrl+Shift+Esc 打开任务管理器 → 启动应用
只保留输入法、声卡、键鼠驱动等必要程序，其余全部禁用，减少开机耗时和后台占用。

五、C盘清理与存储优化

  1. 设置 → 系统 → 存储，开启【存储感知】，自动清理临时文件、回收站。
  2. 磁盘清理：右键C盘 → 属性 → 磁盘清理，勾选更新缓存、临时文件，点击清理系统文件。
  3. 转移用户文件夹：桌面、文档、下载、图片，右键属性 → 位置，移动到D盘，避免C盘很快占满。

六、任务栏、资源管理器习惯设置

  1. 任务栏右键 → 任务栏设置：关闭小组件、搜索框、聊天、新闻和兴趣
  2. 文件资源管理器查看选项：勾选「文件扩展名」「隐藏的项目」，防止误修改后缀名
  3. 任务栏按钮合并方式：设置为「从不合并」，多窗口调试、查看日志更方便

七、安全软件选择

  • 轻量推荐：火绒安全软件，自带弹窗拦截、启动项管理、右键菜单清理，安静无广告
  • 新手推荐：微软电脑管家，一键清理垃圾、管理启动项

不要同时安装多款杀毒软件，容易冲突、卡顿。Windows Defender 默认防护足够日常使用。

八、常备工具清单

  • 解压工具：RAR
  • 文本代码编辑：VS Code
  • 截图工具：Snipaste
  • 终端：Windows 终端 / Tabby
  • 磁盘健康查看：CrystalDiskInfo

九、N 卡控制面板游戏专项优化（NVIDIA 显卡）

右键桌面打开「NVIDIA 控制面板」，管理 3D 设置，全局设置推荐如下：

  1. 电源管理模式：最高性能优先（重点，提升帧率稳定性）
  2. 低延迟模式：关（FPS 竞技游戏优先，降低输入延迟；单机游戏可设为开）
  3. 垂直同步：关（游戏内单独开启，避免强制锁帧）
  4. 最大预渲染帧数：使用默认设置
  5. 着色器缓存大小：使用默认设置
  6. 纹理过滤 - 质量：使用默认设置
  7. 硬件加速 GPU 计划：系统设置内开启（Win11 默认开启）
  8. 帧生成：在支持 DLSS3 的游戏内开启，全局不要强制开启

注意：

  • 竞技 FPS 游戏（CS2 等）优先低延迟、高性能；
  • 3A 单机游戏可以适当调高纹理质量，兼顾画质；
  • A 卡用户直接在 AMD Adrenalin 软件内开启「Radeon Boost」「Anti-Lag」。

十、重要避坑提醒

  1. 不要随便网上下载一键优化脚本，很多脚本删除必要系统组件，后续更新、虚拟机、专业软件直接报错。
  2. 优化不是越精简越好，数控软件、开发工具、虚拟机依赖大量系统组件，过度精简极易翻车。
  3. 不要永久禁用系统更新，可以暂停更新，定期手动安装安全补丁。
  4. 重要资料不要放在 C 盘，养成备份习惯。

本文优化方案优先稳定，适合办公、数控调试、程序开发以及游戏主机，可以按需挑选设置项。
